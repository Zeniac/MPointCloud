# Binary Distribution

MPointCloud is distributed as proprietary closed-source binaries.

## NuGet

```bash
dotnet add package MPointCloud --version 0.9.0-preview.2
```

## Standalone

Download the `MPointCloud-0.9.0-preview.2-net10.0.zip` asset from the corresponding GitHub Release.

The public repository intentionally contains documentation and consumer sample source, not the proprietary MPointCloud implementation source.

# Support and Feedback

MPointCloud is maintained by Mekneo. It is a standalone point-cloud I/O library for .NET 10.

## Bugs and feature requests

Use [GitHub Issues](https://github.com/Zeniac/MPointCloud/issues) for reproducible bugs, documentation corrections, and feature requests. Search existing issues before opening a new one.

For a bug report, include:

- MPointCloud package version and whether you use NuGet or the standalone DLL.
- Operating system, .NET runtime/SDK version, and application architecture.
- File format, encoding, schema and approximate point count.
- The API call and relevant read/write options.
- Expected behavior, actual behavior, and the complete exception message/stack trace.
- A small reproducer and synthetic input that you may share publicly.

Keep client-owned, confidential and personal data out of public issues. Reduce a failing file to a small synthetic example when possible.

When reporting a Mektral integration problem, identify whether it occurs when calling MPointCloud directly or only through the Mektral adapter. Include both product versions.

## Private inquiries

For private inquiries or a suspected security issue, use **Contact owners** on the [NuGet package page](https://www.nuget.org/packages/MPointCloud). Do not post sensitive details publicly. A dedicated Mekneo contact address will be added when available.

## Tell us about your product

If you find MPointCloud useful, you may share your company/product name, an optional website, and a short usage description through **Contact owners**. State whether we may list the name and link publicly. Reporting usage is voluntary and separate from license attribution; logos and testimonials require separate permission.
